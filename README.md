# GuessWhoAmI

Ежедневные мини-игры на знание про-игроков **Counter-Strike** и **Dota 2**. Статический сайт без сервера и сборки:
все данные лежат в готовых JSON-файлах, собранных с [Liquipedia](https://liquipedia.net/).

## Режимы

| Режим | Как играть |
|---|---|
| **Сетка** | Поле 3×3: у каждой строки и столбца есть условие (играл за команду, страна, роль, возраст, число мэйджоров/TI). Впишите в клетку игрока, подходящего под оба условия. 9 попыток, игрок используется один раз. **Своё:** очки уникальности, чем менее очевидный игрок, тем больше очков. |
| **Кто я?** | Как Wordle: угадайте загаданного игрока за 8 попыток. После каждой догадки подсказки по стране, команде, роли/позиции, возрасту и числу мэйджоров/TI (зелёный = совпало, жёлтый = близко, стрелка = больше/меньше). **Своё:** после 4 промахов открываются подсказки (бывшая команда, инициалы). |
| **Цепочка** (свой режим) | Соедините двух игроков через тиммейтов: каждый следующий игрок должен был играть в одной команде одновременно с предыдущим. Цель: уложиться в минимальное число звеньев. Есть отмена шага и подсказки. |

У каждого режима есть **ежедневная** версия (одна и та же для всех, сохраняется прогресс и серия) и **бесконечная**.
Кнопка «Поделиться» копирует результат эмодзи-сеткой.

## Запуск

Нужен любой статический сервер (из-за `fetch` и ES-модулей сайт нельзя открыть просто двойным кликом по файлу):

```bash
cd public
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для хостинга достаточно залить папку `public/` на GitHub Pages, Netlify, Vercel или Cloudflare Pages.

## Данные

- `data/raw/*.json` — кэш сырых данных из Liquipedia API.
- `scripts/build-dataset.mjs` — превращает кэш в компактные `public/data/cs.json` и `public/data/dota.json` (без обращений в сеть).
- `scripts/fetch-liquipedia.mjs` — обновление кэша из Liquipedia API.

Сейчас в базе:
- **CS:** 475 игроков всех 9 мэйджоров от ELEAGUE Boston 2018 до BLAST Austin 2025, с полной историей команд.
- **Dota 2:** 279 игроков TI 2019–2025, Riyadh Masters 2023 и EWC 2025. История команд для Dota строится по этим турнирам, потому что в инфобоксах Liquipedia она генерируется автоматически.

Обновление:

```bash
LIQUIPEDIA_UA="GuessWhoAmI/1.0 (https://ваш-сайт; ваша@почта)" node scripts/fetch-liquipedia.mjs
node scripts/build-dataset.mjs
```

Скрипт соблюдает [правила API Liquipedia](https://liquipedia.net/api-terms-of-use): понятный User-Agent с контактом, gzip,
до 50 страниц в одном запросе, не чаще 1 запроса в 2,5 секунды, все ответы кэшируются в `data/cache/`. Сайт **никогда** не ходит в
Liquipedia сам, только читает готовый JSON.

Чтобы добавить турниры, допишите их в `CS_MAJORS` / `DOTA_EVENTS` в `fetch-liquipedia.mjs`.
Чтобы добавить новую игру (Valorant, LoL…), нужен новый блок в обоих скриптах и запись в `GAMES` в `public/js/core.js`.
Если сборка пишет `countries missing`, добавьте страну в `scripts/countries.mjs`.
