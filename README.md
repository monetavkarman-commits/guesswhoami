# GuessWhoAmI

Ежедневные мини-игры на знание игроков: киберспорт (**Counter-Strike**, **Dota 2**, **VALORANT**, **League of Legends**) и спорт (**футбол**, **баскетбол**, **Формула-1**, **теннис**). Статический сайт без сервера и сборки:
все данные лежат в готовых JSON-файлах, собранных с [Liquipedia](https://liquipedia.net/).

## Режимы

| Режим | Как играть |
|---|---|
| **Сетка** | Поле 3×3: у каждой строки и столбца есть условие (играл за команду, страна, роль, возраст, число мэйджоров/TI). Впишите в клетку игрока, подходящего под оба условия. 9 попыток, игрок используется один раз. **Своё:** очки уникальности, чем менее очевидный игрок, тем больше очков. |
| **Кто я?** | Как Wordle: угадайте загаданного игрока за 8 попыток. После каждой догадки подсказки по стране, команде, роли/позиции, возрасту и числу мэйджоров/TI (зелёный = совпало, жёлтый = близко, стрелка = больше/меньше). **Своё:** после 4 промахов открываются подсказки (бывшая команда, инициалы). |
| **Оружие / Карты** (CS), **Герои** (Dota 2) | Wordle по предметам игры: тип, сторона, цена, магазин и страна для оружия; статус в маппуле, сценарий, тема, страна и автор для карт; атрибут, атака, роли, скорость, дальность и год выхода для героев. Значения из инфобоксов Liquipedia. |
| **Цепочка** (свой режим) | Соедините двух игроков через тиммейтов: каждый следующий игрок должен был играть в одной команде одновременно с предыдущим. Цель: уложиться в минимальное число звеньев. Есть отмена шага и подсказки. |

У каждого режима есть **ежедневная** версия (одна на всех, с серией побед и таймером до следующей) и **бесконечная**.
«Поделиться» копирует результат эмодзи-квадратиками.

### Что ещё есть
- **Очки** в каждом режиме: меньше попыток и подсказок = больше очков (до 1000).
- **Подсказки** за очки или попытки: в «Кто я?» бывшая команда и инициалы, в сетке первая буква и страна, в цепочке следующий шаг.
- **Фильтры сложности**: все игроки, только звёзды, актуальные составы, эры (CS:GO / CS2, TI 2019–2022 / 2023–2025, VCT 2021–2023 / 2024–2026, Worlds 2021–2023 / 2024–2026). В эрах учитываются только периоды, когда игрок реально играл за команду: скамейка («Inactive») не считается.
- **Статистика и 13 достижений** (кнопка 🏆).
- **Deadlock** (киберспорт, два режима «Герои» и «Предметы»): 48 героев и 126 предметов с Liquipedia Deadlock (инфобоксы героев и предметов, уровень предмета по панели предметов). Собирается `scripts/build-deadlock.mjs` из `data/raw/deadlock-raw.json`.
- **Дуэль по ссылке** (сейчас выключена, флаг `DUELS` в `public/js/app.js`): после бесконечной игры появляется ссылка-вызов, у друга будет та же игра, в конце видно, кто набрал больше.
- **Рейтинг** (кнопка 🏅): общий лидерборд за день и за всё время. Работает, когда сайт открыт как артефакт Claude
  (данные лежат во встроенной базе артефакта); на обычном хостинге кнопка показывает пояснение.
- **RU / EN**, светлая и тёмная тема, установка как приложение (PWA) и работа офлайн.

## Запуск

Нужен любой статический сервер (из-за `fetch` и ES-модулей сайт нельзя открыть просто двойным кликом по файлу):

```bash
cd public
python3 -m http.server 8000
# открыть http://localhost:8000
```

Для хостинга достаточно залить папку `public/` на GitHub Pages, Netlify, Vercel или Cloudflare Pages.

## Данные

- `data/raw/*.json` — кэш сырых данных из Liquipedia API.
- `scripts/build-dataset.mjs` — превращает кэш в компактные `public/data/cs.json` и `public/data/dota.json` (без обращений в сеть).
- `scripts/fetch-liquipedia.mjs` — обновление кэша из Liquipedia API.

Сейчас в базе:
- **CS:** 475 игроков всех 9 мэйджоров от ELEAGUE Boston 2018 до BLAST Austin 2025, с полной историей команд.
- **Dota 2:** 279 игроков TI 2019–2025, Riyadh Masters 2023 и EWC 2025. История команд для Dota строится по этим турнирам, потому что в инфобоксах Liquipedia она генерируется автоматически.
- **VALORANT:** 340 игроков Champions 2021–2026, Masters и LOCK//IN 2022–2026 (команды по турнирам, ролей в данных нет, поэтому в сетке вместо ролей регионы).
- **League of Legends:** 332 игрока Worlds 2021–2026 и MSI 2022–2026, с позициями.
- **Предметы:** 127 героев Dota 2, 178 предметов лавки Dota 2 (Liquipedia, цена считается с компонентами и рецептом), 173 чемпиона LoL и 214 предметов LoL для Ущелья призывателей (Riot Data Dragon, с русскими названиями), 34 оружия CS2, 27 карт CS (`scripts/build-items.mjs` из `data/raw/items-raw.json` и `data/raw/items2-raw.json`). Предметы LoL используются по правилам Riot для фан-проектов: сайт бесплатный и не связан с Riot Games.

- **Футбол:** ~1500 известных игроков 1965 г. р. и младше, клубы с датами (Wikidata, CC0). Молодёжные и вторые составы не учитываются.
- **Баскетбол:** ~270 игроков, в основном НБА (Wikidata).
- **Теннис:** ~220 игроков ATP/WTA, только режим угадайки (Wikidata).

Спорт собирается `scripts/build-sports.mjs` из `data/raw/*-wd.json`.

Сырые данные VALORANT, LoL, предметов и пометки периодов в командах CS (`data/raw/cs-th.json`) собраны теми же медленными
запросами к API (до 50 страниц за запрос, пауза 6 секунд), но через браузер; в `fetch-liquipedia.mjs` пока есть только CS и Dota.

Обновление:

```bash
LIQUIPEDIA_UA="GuessWhoAmI/1.0 (https://ваш-сайт; ваша@почта)" node scripts/fetch-liquipedia.mjs
node scripts/build-dataset.mjs
```

Скрипт соблюдает [правила API Liquipedia](https://liquipedia.net/api-terms-of-use): понятный User-Agent с контактом, gzip,
до 50 страниц в одном запросе, не чаще 1 запроса в 2,5 секунды, все ответы кэшируются в `data/cache/`. Сайт **никогда** не ходит в
Liquipedia сам, только читает готовый JSON.

Чтобы добавить турниры, допишите их в `CS_MAJORS` / `DOTA_EVENTS` в `fetch-liquipedia.mjs`.
Чтобы добавить новую игру, нужен новый блок в скриптах и запись в `GAMES` в `public/js/core.js`.
Если сборка пишет `countries missing`, добавьте страну в `scripts/countries.mjs`.
